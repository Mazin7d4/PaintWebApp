# Palette Journal - Critical UX & Accessibility Learnings

## 2025-05-20 - Vibrant Modern Canvas Toolbar Pattern
**Learning:** High-contrast floating toolbars with SVG icons, live brush size indicators, and preset color swatches dramatically improve canvas discoverability and engagement, while explicit `aria-label`s and visible focus rings keep rich canvas applications fully accessible to keyboard and screen-reader users.
**Action:** Always complement visual canvas controls with semantic ARIA labels, live textual status badges, and keyboard shortcuts (`C`, `S`).
